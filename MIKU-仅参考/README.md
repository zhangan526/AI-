# 桌面宠物

当前工程版本：1.7.0（miku 最终版）。应用名称为 `miku`，图标使用用户提供的初音未来图片。

一个适合入门学习的 Android 悬浮窗桌宠示例。支持开启/关闭、随机表情、自由行走、拖拽移动、位置记忆、待办奖励和本地时间行为。

当前版本已内置 `D:\app\表情` 中的 9 类、40 个素材，首次启动会复制到 App 私有目录并按 `bored/click/eat/happy/play/random/sad/sleep/walk` 分类加载。

番茄钟 / 专注拦截接入了开源项目 [Reef](https://github.com/aload0/Reef)（MIT）。主页面和桌宠小窗都可以打开「番茄钟」；设置页里会保留指向原仓库的署名。衍生使用不得继续使用 Reef 名称与图标。

当前版本已移除待办时间提醒和素材导入入口。控制小窗使用动态待办列表：点击“+”可增加条目，完成一条待办会获得 1 份食物并增加心情值，删除按钮可移除条目。

心情值和饥饿值按真实经过时间衰减，每 24 小时约降低 40 点；应用关闭期间的时间会在下次打开时补算。饥饿值降为 0 时心情值立即归零。

## 运行

1. 使用 Android Studio 打开本目录。
2. 等待 Gradle 同步完成（项目使用 JDK 17、Android SDK 37、AGP 9.2、Gradle 9.5）。本机可用 FlClash 混合端口 `127.0.0.1:7890` 加速依赖下载，已写在 `gradle.properties`。
3. 连接 Android 8.0 或更高版本的真机并点击 Run。
4. 点击“开启桌宠”，在系统页面允许“显示在其他应用上层”。
5. 使用番茄钟时，按提示授予用量访问和无障碍（应用拦截）权限。

内置素材在首次启动时复制到 App 私有目录 `filesDir/pet_assets`，运行时不读取电脑上的 `D:\app`。所有状态都显示在同一个固定大小的 `PetCanvas` 中，使用 `CENTER_INSIDE` 居中等比例缩放；GIF 在 Android 9 及以上循环播放，没有素材的状态自动使用待机素材。

## 桌宠控制界面

点击桌面上的应用图标会打开主页面，主页面保留宠物图片、心情值、饥饿值、食物数量、喂食、摸摸、睡觉、自由行走开关、宠物大小、行走速度和开启/关闭桌宠；大小与速度设置会保存到本地。

长按悬浮宠物会在宠物旁边直接打开真正的系统悬浮小窗，即使当前正在使用其他应用也不会跳回主页面。小窗左侧只包含自由行走开关、关闭宠物和添加待办，右侧以待办内容为主；单条待办点开后才显示完成/删除按钮，右上角“×”只关闭小窗。单击宠物按 `play/random/bored/心情` 的 `1:1:1:2` 权重切换表情，双击播放 `click` 素材并增加心情值。

“关闭宠物”会调用 `stopService`，真正移除悬浮窗并停止前台服务。宠物大小和半隐藏只改变 `PetCanvas` 内部图片的视觉缩放/透明度，固定容器宽高不变。

## 自由行走与本地时间

开启自由行走后，宠物会在屏幕可用范围内随机选择目标和停留时间，不按照固定路线移动。每段移动都从 `walk` 分类随机抽取 GIF，并且仅在确定新目标时按水平方向镜像一次，不会在行走途中随意改变朝向。喂食会从 `eat` 分类随机抽取素材，互动结束后再恢复行走。

时间规则集中在 `TimeBehaviorConfig`，使用手机本地 `LocalTime`，每 60 秒检查一次：23:00 至 07:00 睡觉，睡觉优先级最高且停止行走；07:00 自动回到待机；12:00 可触发一次喂食状态。动作使用时间键去重，不会每次检查都重复播放。

## PetCanvas 尺寸

默认尺寸集中在 `PetCanvasConfig`：按照当前屏幕的 4 列 × 6 行网格取一个单元格，再乘以 `DEFAULT_CANVAS_SCALE = 2/3`。因此 PetCanvas 和其中的图片一起缩小到原来的三分之二，触摸区域也同步缩小。配置会同时使用 `screenWidth`、`screenHeight` 和 `density` 计算 px/dp，所有状态共用同一宽高；屏幕旋转后会重新计算悬浮窗尺寸，图片仍由 `CENTER_INSIDE` 保持比例，不会拉伸。

首次构建需要联网下载 Gradle 和 Android 依赖。部分手机还需在系统设置中允许应用后台运行。

## 图片

`pet_01.png` 到 `pet_06.png` 来自用户提供的角色表情。处理程序只移除了与图片边缘相连的近白色背景，并保留角色内部的白色区域。
