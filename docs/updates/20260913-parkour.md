## 当前依赖与合并边界

这是增量源码包，不是可单独编译的完整 Android 工程。代码引用当前 main 中没有的 TetrisArena、PetHomeActivity、home_panel_bg 等资源/类；因此本分支将完整包作为 ParkourUpdate/ 快照保存，没有覆盖 GuardPet/ 主工程。

要合入产品工程时，应把 ParkourUpdate/GuardPet/ 下的文件复制到对应 GuardPet/ 路径，并同时补齐上述依赖；再在 Manifest 注册 GameActivity，在主页/桌宠菜单增加入口，最后运行 GuardPet/gradlew.bat :app:assembleDebug。

## 操作说明

- 点击游戏画面：跳跃，空中再次点击执行二段跳
- 按住“下蹲 / 快速下落”：躲过悬浮横杆或快速落地
- 跑酷得分可转换为食物奖励（奖励逻辑由 GameActivity 负责）
