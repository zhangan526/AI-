# 守伴

## 本分支：DeepSeek Agent 接口版 · 2026-09-12

分支：`codex/guardpet-deepseek-agent-20260912`。基于 `main` 的 `7bf62be`，整合用户提供的 19 个增量文件，包含可独立打开的完整 `GuardPet/` 工程。

新增主页和桌宠菜单里的「守伴 Agent」入口、DeepSeek 文本对话、API Key 加密保存，以及摸摸、喂食、睡觉、保存闪记四类动作。当前是页面内会话与动作接口版本；真实 API 和手机交互尚未验证。

本次完整工程 Debug 编译通过（79 个任务）。

本分支沿用 GuardPet UI，与 `codex/ui-miku-modern` 的独立 Miku UI 版本分开。详细变更、使用方法和验证记录见 [DeepSeek 接口版更新说明](docs/updates/20260912-deepseek-agent.md)。

陪伴守护形桌宠。应用名「守伴」，包名 `com.geekathon.guardpet`。

用 Android Studio 打开 **`GuardPet/`** 目录（不要打开仓库根目录）。

## 本版能力

- 悬浮窗桌宠：拖拽、行走、心情/饥饿、到点睡觉；手势可在设置里绑定快捷功能
- 双击菜单：提取文字、闪记、番茄钟、控制小窗（右上角 X 关闭）
- 番茄钟 / 应用与网站拦截：接入开源 [Reef](https://github.com/aload0/Reef)（MIT，设置页保留署名，不得使用 Reef 名称与图标）
- 提取文字：无障碍读取当前界面，分词后点选/反选，再复制、搜索或送进闪记
- 闪记：语音或手动输入，必须选择日程/灵感/日记/待办/其他；日程带日期
- 夜间作息守护：规则引擎根据用量、今日日程和习惯，禁用无关应用，或锁机催睡，或只放行相关应用

## 运行

1. 用 Android Studio 打开 `GuardPet`
2. JDK 17、Android SDK 37、AGP 9.2、Gradle 9.5
3. 真机 Android 8.0+ 安装运行
4. 开启桌宠时允许「显示在其他应用上层」
5. 番茄钟 / 提取文字 / 夜间拦截需要用量访问和无障碍「守伴守护」
6. 语音闪记需要麦克风权限

`MIKU-仅参考/` 是桌宠骨架对照工程，不要当产品改。约定见 `AGENTS.md`。

专注功能基于 Reef。衍生使用必须在设置或关于页保留指向原仓库的链接。
